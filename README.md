# 本地密码派生工具

### **本版本生成的密码会与前序版本不再兼容！！**
一个简单的**确定性密码派生工具**，根据主密码、盐和网站标识生成站点专属的强密码。无需存储密码数据库，只需记住主密码、盐和标识名即可离线复现所有密码。
- 版本：**v2.0-alpha**  
  - `alpha` 表示测试版本。  
  - `2` 代表核心算法主版本，相同主版本的密码可互相兼容。本版本生成的密码会与前序版本 `v1.x` 不再兼容！！
  - `0` 代表该主版本下的迭代次数。

---
## 用户使用更改
- 现在不能在命令行内输入 `-s --salt` 参数，而是需要和密码一起输入。
- 将原来的参数 `-w --website` 更改为 `-s --site-name`
- 新增了 `-f --fast` 参数，启动后只用输入密码和盐一次，无需再次确认。
- 现在两次输入密码或盐不一致，不会导致程序退出，而是会再次请求输入。
- 现在不再进行对标识名(`-s`)进行域名规范化，只进行小写化。
- 新增了 `--show` 参数，启动后会打印生成的密码（类似前序版本），默认不开启。
- 现在在默认情况下，生成的密码会自动复制到用户的剪切板中， 10 秒后自动被 `密码已经被清除。请重新生成。` 覆写。
- 为了避免与网站政策冲突，现在默认符号集为 `!@#$%^&*()_+-=` 而不是之前的 `string.punctation`。

---
## 技术细节更改
- 将原来 `main.py` 拆分为两个文件 `core.py` 和 `cli.py`。
- 引入了 `hmac` 、 `time`内部库（为了进行 hmac 扩展操作）和 `pyperclip` 外部库（为了进行剪切板操作）。
- 拆分了原来的密码派生函数为 `derive` 和 `assemble` 两部分，便于调试和进一步引入更多加密算法。
- 原算法采用取双位法进行二进制到字符索引的转化，不同字符之间会产生 `1/65536` 的模数偏差，用拒绝采样重写了这一部分，完全杜绝该情况。
- 尽管在python下很困难，我们尝试使用 `del` 和 `bytearray` 覆写和清除原密码和盐。
- 使用了 `HMAC` 算法，会在索引使用完毕时生成新的，使得可以理论上生成无限长的密码，但建议不要尝试超过 256 位的密码生成，因为极长密码会导致生成时间显著增加。

## 用法

```bash
python derive_password.py -s <site_name> [-l <length>] [-f] [--no-special] [--special-chars <chars>] [--show]
或者
derive2.0.exe -s <site_name> [-l <length>] [-f] [--no-special] [--special-chars <chars>] [--show]
```
`-s`参数填写登录站点的名称，填写便于记忆的格式，如（google、支付宝-小号等等）

运行后会提示输入主密码和盐，在未开启 `-f` 的情况下会确认一次，如果确认不通过，会提示重新输入，随后输出生成的密码。
在开启 `-f` 的情况下，没有确认环节。

生成的密码一定包含大写字母、小写字母、 数字和特殊字符(在`--no-special`为`False`的情况下)这些类型的字符各一个。
自定义符号集时，生成的密码的特殊符号选取于自定义的版本。默认情况下符号集为 `!@#$%^&*()_+-=`

在默认情况下，生成的密码会传输进入用户的剪切板 10 秒，随后被替换成其他字符。
在 `--show` 启动的情况下会直接打印密码，请在选择时谨慎，注意运行环境的安全。

### 命令行参数
| 参数	            | 简写	 | 必选	 | 说明                                                                               |
|-----------------|------|------|------------------------------------------------------------------------------------|
| --site-name	     | -s	   | 是	   | 标识 (如 'google'、'小红书-大号'等)。                                              |
| --fast	          | -f	   | 否	   | 启动快速模式，只用填写一次密码和盐。                                               |
| --length	        | -l	   | 否	   | 密码长度，默认 16，范围 大于选定的字符类型数（默认为4，--no-special为True时为3）。 |
| --no-special	    | 无	   | 否	   | 不启用特殊字符。                                                                   |
| --special-chars	 | 无	   | 否	   | 自定义特殊字符，可传入自定义字符集。**请务必牢记！**                               |
| --show	          | 无	   | 否	   | 直接打印密码。**危险！**                                                           |

```bash
# 为标识 'google.com' 生成默认位数不含符号的密码，使用快速模式，需要输出在控制台。

derive2.0.exe -s google.com -f --no-special --show
```

## 安全须知
- 请记牢标识名，使用容易记住的构造方法。

- 盐必须保密，且区别于他人，和密码需同等对待。

- 主密码使用高熵、易记忆的长主密码。避免常见词汇。

- 离线使用：该工具完全离线运行，不会上传或记录任何数据。请在可信的本地环境中执行。

- 打印生成密码请注意运行环境可信，使用环境无被窃取的风险。

- 确定性风险：如果主密码和盐同时泄露，所有站点密码可被准确计算。务必保护好这两个秘密。

- 符号集修改警告：如果你修改了 `--special-chars`，以后必须使用完全相同的符号集才能重现密码，否则会得到不同结果。
