# 本地密码派生工具

一个简单的**确定性密码派生工具**，根据主密码、盐和网站标识生成站点专属的强密码。无需存储密码数据库，只需记住主密码和盐即可离线复现所有密码。
- 版本：**v1.0-alpha**  
  - `alpha` 表示测试版本。  
  - `1` 代表算法主版本，相同主版本的密码可互相兼容。  
  - `0` 代表该主版本下的迭代次数。

---

## 依赖

- Python 3.6 或更高版本
- 标准库（`sys`, `hashlib`, `argparse`, `getpass`, `string`），无需安装第三方包。

## 用法

```bash
python derive_password.py -s <salt> -w <website> [-l <length>] [--no-special] [--special chars <chars>]
```
运行后会提示输入主密码并确认一次，随后输出生成的密码，生成的密码一定包含大写字母`(string.uppercase)`、小写字母`(string.lowercase)`、
数字`(string.digit)`和特殊字符`(symbols)`(在`--no-special`为`False`的情况下)这些类型的字符各一个。

### 命令行参数
| 参数	            | 简写	 | 必选	 | 说明                                                                                                        |
|-----------------|------|------|-------------------------------------------------------------------------------------------------------------|
| --salt	          | -s	   | 是	   | 盐，应保密且长度足够。                                                                                      |
| --website	       | -w	   | 是	   | 站点标识（如 google.com），会自动转为小写。                                                                 |
| --length	        | -l	   | 否	   | 密码长度，默认 16，范围 大于选定的字符类型数（默认为4，--no-special为True时为3）。                          |
| --no-special	    | 无	   | 否	   | 启用特殊字符；默认为True；写下即为False。                                                                   |
| --special-chars	 | 无	   | 否	   | 仅在 --no-special 有效时指定符号集，默认为 string.punctuation。**除非你能记住自定义符号集，否则不要修改！** |

### 示例
```bash
# 为 google.com 生成 16 位不含符号的密码
python derive_password.py -s "my_secret_salt" -w google.com

# 为 github.com 生成 20 位且包含特殊字符的密码
python derive_password.py -s "my_secret_salt" -w github.com -l 20 --force-symbol

# 使用自定义符号集（仅 !@#$%）
python derive_password.py -s "my_secret_salt" -w example.com --force-symbol --symbols '!@#$%'
运行示例输出：

text
为站点 'google.com' 生成密码...
请输入主密码: 
请再次输入主密码: 

生成的密码: ……
```
### 工作原理
组合 `site:master_pass`，与用户提供的 `salt` 一起送入 `PBKDF2‑HMAC‑SHA256`（60 万次迭代），生成特定的索引。

程序根据索引先强制生成 `4`（`--no-special`为`True`时为`3`） 种类型的字符各一个，再填充剩下的空位。随即返回输出并打印。

## 安全须知
盐必须保密：盐是派生过程中关键的秘密输入。如果盐泄露，攻击者只需爆破主密码即可生成所有站点密码。

主密码强度：使用高熵、易记忆的长主密码。避免常见词汇。

离线使用：该工具完全离线运行，不会上传或记录任何数据。请在可信的本地环境中执行。

确认输入：程序会要求两次输入主密码，防止手误。生成密码后请立即复制使用，不要保留在剪贴板。

确定性风险：如果主密码和盐同时泄露，所有站点密码可被准确计算。务必保护好这两个秘密。

符号集修改警告：如果你修改了 --symbols，以后必须使用完全相同的符号集才能重现密码，否则会得到不同结果。
