# Local Password Derivation Tool

[中文](README.zh.md)

> **⚠️ Passwords generated by this version are no longer compatible with previous versions (`v1.x`)!**

A simple **deterministic password derivation tool** that generates a unique, strong password for each site from a master password, a salt, and a site identifier. No password database is stored — just remember your master password, salt, and identifier to reproduce all your passwords offline.

- Version: **v2.1-alpha**
  - `alpha` indicates a testing version.
  - `2` is the core algorithm major version. Passwords within the same major version are mutually compatible; this version is **not** compatible with `v1.x`.
  - `1` is the iteration number within this major version.

---

## Features

- **Deterministic**: the same inputs always produce the same password.
- Generated passwords always contain at least one uppercase letter, lowercase letter, digit, and special character (unless `--no-special`).
- **Parameter presets** (`config`): store and manage non-secret parameters (length, symbol set) as named presets.
- **Identifier normalization**: lowercase and trim surrounding whitespace only — no domain extraction.
- **Warnings** for URL-like and IP-like identifiers (no silent rewriting).
- **Internationalization**: English built-in, Simplified Chinese bundled.
- Clipboard auto-copy (cleared automatically after 10 seconds), or `--show` to print.

## Usage

```bash
passderive derive -s <site> [-n <note>] [-c <id|name>] [-l <length>] [--no-special] [--special-chars <chars>] [-f] [--show]
```

`derive` is the default subcommand, so the shorter form also works:

```bash
passderive -s <site> ...
```

Running from a source checkout without installing uses `python -m passderive.cli` instead.

- `-s` is the site identifier (e.g. `google`, `xiaohongshu`).
- `-n` is an optional note for distinguishing multiple accounts on the same site (e.g. `work`, `alt`). When set, the derivation input becomes `site|note` (e.g. `google|work`).

After running, you are prompted for the master password and the salt. Without `-f`, each is confirmed once and a mismatch asks you to re-enter (three attempts before exit). With `-f`, there is no confirmation step.

By default, the generated password is copied to the clipboard and replaced after 10 seconds. Use `--show` to print it instead — be careful to run in a safe environment.

### Parameter presets (`config`)

Manage non-secret parameters (length and symbol set) as named presets. Each preset has a numeric ID and a name; the default preset is ID `0` named `default` (editable, not removable). Presets are stored in `config.json` under the user configuration directory (`%APPDATA%\passderive` on Windows, `~/.config/passderive` on Linux, `~/Library/Application Support/passderive` on macOS); for the portable executable, it stays next to the executable. Override with the `PASSDERIVE_CONFIG` environment variable.

```bash
passderive config list
passderive config add <name> [-l <length>] [--no-special | --special-chars <chars>]
passderive config remove <id|name>
passderive config edit <id|name> [-n <name>] [-l <length>] [--no-special | --special-chars <chars>]
```

In `derive`, `-l` and `--special-chars` are temporary overrides. Effective parameters resolve in this order:

1. Explicit `-l` / `--special-chars` (temporary)
2. The preset selected with `-c <id|name>`
3. The default preset (ID `0`)

The effective preset and parameters are always printed before derivation (e.g. `Using preset 1 'strong' (length 20, symbols @#$)`), so you can catch a wrong selection before it matters.

### Command-line arguments (`derive`)

| Option          | Short | Required | Description                                                              |
|-----------------|-------|----------|--------------------------------------------------------------------------|
| --site-name     | -s    | yes      | Site identifier (e.g. 'google', 'xiaohongshu').                          |
| --notes         | -n    | no       | Note to distinguish multiple accounts on the same site; none by default. |
| --config        | -c    | no       | Preset ID or name to use.                                                |
| --length        | -l    | no       | Password length (temporary override).                                    |
| --fast          | -f    | no       | Fast mode: enter the password and salt only once.                        |
| --no-special    |       | no       | Disable special characters.                                              |
| --special-chars |       | no       | Custom special characters (temporary override).                          |
| --show          |       | no       | Print the password directly. **Dangerous!**                              |

### Examples

```bash
# Derive a password for 'google.com' with no special characters, fast mode, printed to the console.
passderive -s google.com -f --no-special --show
```

```text
Using preset 0 'default' (length 16, no symbols)
Generating a password for the identifier “google.com”...
Enter the password:
Enter the salt:

Password generated:
# your password
Please clear the screen promptly.
```

```bash
# Derive a 20-character password for 'tiktok-运营号' with the default symbol set.
passderive -s tiktok-运营号 -l 20
```

## Internationalization

The source strings are English. Simplified Chinese (`zh_CN`) is bundled under `locale/`. The interface language is chosen via the environment (`LANGUAGE` / `LC_ALL` / `LC_MESSAGES` / `LANG`) or, if unset, the system locale, falling back to English.

To update or add translations, edit `src/passderive/locale/zh_CN/LC_MESSAGES/passderive.po` and run:

```bash
python compile_locale.py
```

## Security

- Remember your identifiers; use a construction rule that is easy to recall.
- Keep the salt secret and distinct from others; treat it like the master password.
- Use a long, high-entropy, memorable master password; avoid common words.
- Offline use: the tool runs fully offline and never uploads or records data. Run it in a trusted local environment.
- Determinism risk: if both the master password and the salt leak, all derived passwords can be recomputed. Protect both secrets.
- Symbol-set warning: if you change `--special-chars`, you must reuse the exact same set — including the order — to reproduce the password.
